## Разрешённые источники изображений

### 1. Собственные изображения
Фото/скрины, сделанные редакцией или легально полученные для конкретного материала. Основной приоритет — всегда предпочтительнее стоков и чужих фото.

### 2. Wikimedia Commons
Проверено напрямую 2026-11-07 ([Commons:Reusing content outside Wikimedia](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia)):

- **Лицензия указывается ПОФАЙЛОВО**, не на уровне всего сайта. Перед использованием любого файла нужно открыть его страницу описания и прочитать конкретную лицензию (CC BY, CC BY-SA, public domain и т.п.) — общая политика сайта не заменяет эту проверку.
- Wikimedia Foundation **не гарантирует точность** разметки лицензии — ответственность за проверку на редакции.
- Возможны **неимущественные ограничения** даже при свободной лицензии: товарные знаки, персональные права (например, коммерческое использование фото человека может требовать его согласия, даже если лицензия на фото разрешает копирование).
- При лицензии **ShareAlike** производная работа (например, кадрированное/отредактированное фото) обязана сохранять ту же лицензию.
- Указывать автора нужно **в формате, который задал сам автор на странице файла**; если формат не задан — по стандартной рекомендации Commons credit line.
- Предпочтительно скачивать файл (хранить с метаданными), а не хотлинкать напрямую с commons.wikimedia.org.

### 3. Unsplash API
Проверено напрямую 2026-11-07 ([api-terms](https://unsplash.com/api-terms), [documentation](https://unsplash.com/documentation)):

- Бесплатный тариф: **demo-режим — 50 запросов/час**; после ручной заявки на production approve — 1000/час.
- Обязательна **атрибуция фотографа и Unsplash** по API guidelines.
- Изображения отдаются только через **hotlink** на `images.unsplash.com` с сохранением параметра `ixid` (так Unsplash считает показы в пользу фотографа) — скачивание и повторная раздача со своего сервера как "подменного" хостинга не допускается без прохождения через download-tracking эндпоинт.
- Регистрация приложения на production-лимит — НЕ покупка, но требует аккаунта; создание нового аккаунта/приложения на чьё-то имя — эскалация Roman.

### 4. Pexels API
НЕ полностью проверено этим прогоном (страница документации вернула 403 нашему инструменту). По общеизвестной лицензии Pexels: бесплатное использование, модификация, без обязательной атрибуции — но **без перепродажи неизменённых фото** и **без implied endorsement** (нельзя представлять фото так, будто изображённые люди/бренды поддерживают материал редакции). Pexels API требует бесплатного API-ключа по регистрации — саморегистрацию не делать, пометить как "требует аккаунта — эскалация Roman", и перед первым использованием заново проверить текст лицензии напрямую на pexels.com/license.

### 5. Официальные пресс-фото госорганов
Из того же реестра, что и `config/sources.yaml`:

- **Офіс Президента України** — фотобанк (`president.gov.ua/en/rss/photos/all.rss`) — заявлен официальной страницей-каталогом фидов, прямой фетч вернул 403 в этом прогоне, требует перепроверки. Условие использования — редакционное, с указанием "Офіс Президента України" как источника, без искажения контекста.
- **Кабінет Міністрів України** — фотогалерея заседаний (`kmu.gov.ua/gallery`) — аналогично, не подтверждено прямым фетчем в этом прогоне, требует перепроверки перед использованием.
- Общее правило для гос. фотобанков: это разрешение на **редакционное** использование (новостная иллюстрация факта), а не карт-бланш на любое коммерческое использование — если на конкретной фото-странице есть отдельная оговорка, она приоритетнее.

### 6. Чего в реестр НЕ включено (и почему)
- Платные фотостоки (Getty, Shutterstock premium и т.п.) — не используем без решения Roman о покупке лицензии.
- Фото, снятое со страниц СМИ/соцсетей без явного разрешения на редакционное использование — paywall/чужой копирайт обходить нельзя.

### Что обязательно хранить для каждого изображения (rights metadata)

| Поле | Описание |
|---|---|
| `author` | Автор/фотограф (как указано источником; если неизвестен — "unknown", не выдумывать) |
| `license` | Код лицензии (CC BY 4.0, CC BY-SA, Unsplash License, Pexels License, "editorial use — press kit" и т.п.) |
| `source_url` | Ссылка на страницу, откуда взято изображение |
| `license_url` | Ссылка на текст самой лицензии |
| `credit_line` | Готовая строка атрибуции для публикации под фото |
| `date_obtained` | Дата, когда изображение было получено редакцией |

### Явные правила (не подлежат трактовке "по ситуации")

1. **Изменение чужого фото (кадрирование, цветокоррекция, коллаж) не создаёт новую лицензию и не даёт прав.** Исходная лицензия/разрешение продолжает действовать на производную версию целиком, включая условия типа ShareAlike или ограничение на коммерческое использование.
2. **AI-иллюстрации разрешены только с явной видимой подписью** вида «ілюстрація, згенерована AI» на самом изображении или в подписи рядом. AI-иллюстрации **никогда** не используются для изображения реальных событий, реальных людей, войны или жертв так, будто это настоящая фотография — это прямой риск дезинформации и репутационный/юридический риск издания.
