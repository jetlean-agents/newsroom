# Дизайн портала v3 — «Новини України» (рабочее название)

FACT-339. Макеты, дизайн-система, обложки рубрик и плейсхолдер логотипа. Код страниц здесь не меняется — это задача Developer, правила ниже.

## Что в папке

| Путь | Что это |
|---|---|
| `tokens.css` | Все токены: цвет (светлая + тёмная тема), типографика, сетка, отступы, радиусы. Единственный источник значений. |
| `prototype/*.html` | HTML-прототипы 6 экранов + `styleguide.html`. Открываются локально в браузере, без сборки. `*.dark.html` — та же страница в тёмной теме. |
| `prototype/prototype.css` | CSS компонентов прототипа (только `var(--…)`). Ориентир для вёрстки, а не обязательный API классов. |
| `prototype/build.py` | Генератор HTML (`python3 design/prototype/build.py`). Тексты в нём — демо-заглушки, не факты. |
| `mockups/*.png` | Рендеры: `<экран>-mobile.png` (390 px, @2x) и `<экран>-desktop.png` (1440 px), плюс `-dark`, `styleguide-desktop.png`, `covers-sheet.png`, `logo-placeholder.png`. |
| `covers/<slug>.svg` | 12 обложек рубрик (slug = `src/lib/rubricsConfig.ts`). `build_covers.py` пересобирает их. |
| `logo/` | Плейсхолдер: `wordmark.svg`, `wordmark-inverse.svg`, `wordtype.svg` (только текст, `currentColor`), `mark.svg`, `favicon.svg`. |
| `fonts/` | Literata и Golos Text (variable TTF) + тексты лицензий OFL — только для прототипов. |
| `check_contrast.py` | Проверка WCAG-контраста всех пар токенов в обеих темах. |

Экраны (каждый в 390 и 1440): главная `index`, рубрика `rubric`, тег `tag`, статья `article`, поиск `search`, 404 `404`.

## Идея

- **Полоса «чернила»** — шапка и футер цвета `--masthead-bg` (тёмный петроль `#0F2A33`), под ней белая строка рубрик. Узнаваемо, но без чужих фирменных приёмов.
- **Хребет времени** в «Останні новини»: колонка времени (Golos Text Bold, табличные цифры), вертикальная линия, точка цвета рубрики. Это главный запоминающийся элемент. «Терміново» — красная точка, красное время и бейдж.
- **Цвет = рубрика.** 12 цветов рубрик используются только для меток, точек в ленте, линии заголовка блока рубрики и обложек. Декоративного цвета нет.
- **Два шрифта с разными ролями:** Literata (антиква) — редакционные заголовки и текст статьи; Golos Text (гротеск) — интерфейс, лента, мета. Заголовки в ленте набраны гротеском: так быстрее сканировать.
- **Честность видна в интерфейсе:** у каждой статьи блоки «Джерела», «Оновлено …», раскрытие ИИ и «Виправлення».

## Шрифты (обе — SIL Open Font License 1.1)

- **Literata** — https://github.com/googlefonts/literata, ось `opsz` 7–72: для заголовков `font-variation-settings: 'opsz' 72`, для текста `'opsz' 14`.
- **Golos Text** — https://github.com/googlefonts/golos-text.

В Next.js подключайте через `next/font/google`, а не из `design/fonts`:

```ts
import { Literata, Golos_Text } from 'next/font/google'
const serif = Literata({ subsets: ['cyrillic', 'latin'], axes: ['opsz'], variable: '--font-serif', display: 'swap' })
const sans = Golos_Text({ subsets: ['cyrillic', 'latin'], variable: '--font-sans', display: 'swap' })
// <html lang="uk" className={`${serif.variable} ${sans.variable}`}>
```

Значения `--font-serif` / `--font-sans` в `tokens.css` — fallback-стек; next/font перекроет их своими переменными.

## Токены — правила

1. `tokens.css` импортируется первым в `src/app/(frontend)/globals.css`. В компонентах — только `var(--…)`, без hex-значений.
2. Текст: `--text`/`--ink` на `--paper`, вторичный — `--muted`. На `--wash` можно всё то же (контраст проверен).
3. `--signal` — только «Терміново» и «Наживо». Не для ошибок форм (для них `--danger`) и не для акцентов.
4. Цвет рубрики берётся из атрибута `data-r="<slug>"`, который выставляет `--rc` (текст/метка), `--rt` (светлая подложка) и `--rcov` (фон обложки, одинаковый в обеих темах). Маппинг — в начале `prototype.css`.
5. Радиусы: 3 px — метки, чипы, поля, кнопки; 6 px — изображения и блоки-подложки. Теней нет.
6. Отступы — шкала `--sp-1…8` (4–64 px). Между секциями главной `--sp-7` (48).

## Сетка и брейкпоинты

| | Колонки | Поле | Межколонник | Примечание |
|---|---|---|---|---|
| < 768 | 4 | 16 | 16 | одна колонка контента; топ-обложка и обложка статьи на всю ширину (`mobile-bleed`) |
| ≥ 768 | 8 | 32 | 24 | |
| ≥ 1200 | 12 | 80 при 1440 | 24 | контейнер 1280; основное 8 кол., правая колонка 4 |

Desktop-раскладки: главная — топ-материал на 8 колонок + лента на 4; «Головне» — 4 карточки по 3; блоки рубрик 2×2 на 8 колонках + правая колонка («Популярне», «Пояснюємо»). Статья, рубрика, тег, поиск — 8 + 4. Правая колонка статьи липкая (`position: sticky`).

Мобильная версия: «Головне» — первая карточка крупно, остальные строками с миниатюрой 4:3 справа. Строка рубрик прокручивается по горизонтали, справа затухание. Тап-цели ≥ 44 px.

## Компоненты ↔ данные Payload (`src/collections/Articles.ts`)

| Компонент | Поля | Правило |
|---|---|---|
| Метка рубрики `.rlabel` | `rubric.slug`, `rubric.title` | Квадрат 8 px + название цветом рубрики. Всегда ссылка на рубрику, кроме ленты. |
| Время в ленте | `published_at` | `HH:mm` по Києву (`Europe/Kyiv`) для сегодняшних; разделитель «Вчора, 8 листопада»; старше — дата. `<time datetime>` обязателен. |
| «оновлено 15:20» | `updated_at`, `update_note` | Показывать, только если обновление было после публикации и `update_note` заполнено. В статье: «**Оновлено** 15:20: {update_note}». |
| Бейдж «Терміново» | — | **Поля нет.** Нужно решение PO (например, `breaking: boolean` + срок жизни 2 ч). До этого бейдж не выводить. |
| Бейдж типа | `content_type` | `news` → «Новина», `evergreen` → «Пояснення». Блок «Пояснюємо» на главной = свежие `evergreen`. |
| Топ и «Головне» | `featured` | Самый свежий `featured` — топ, следующие 4 — «Головне». Если `featured` меньше 5, добирать свежими `news`. |
| «Популярне» | `page_views` | Ранжированный список из 5 позиций; номер — место в рейтинге, поэтому здесь нумерация уместна. |
| Автор | `author` | Только реальный пользователь или «Редакція». Колонки — только при реальном авторе с профилем (см. styleguide); фото — только своё и с разрешением, иначе инициалы. |
| Раскрытие ИИ | `ai_assisted`, `ai_disclosure` | При `ai_assisted = true` блок обязателен, сразу после обложки. Текст — `ai_disclosure` + ссылка «Як ми працюємо». |
| «Коротко» | — | Опционально: 2–4 пункта, если пайплайн их генерирует. Нет данных — блок не выводить. |
| «Джерела» | `sources[]`: `title`, `url`, `publisher`, `accessed_at` | Нумерованный список (номер = источник). Строка: ссылка-заголовок, ниже «{publisher}, переглянуто {accessed_at}». Внешние ссылки `rel="noopener"`, без `nofollow`-спама. Под списком — «Помітили неточність?» и ссылка на «Виправлення». |
| «Виправлення» | `corrections[]` | Красная левая линия; дата и текст. Нет записей — блока нет. |
| Теги | `tags[]` | Чипы-ссылки на `/tag/<slug>`. |
| «Читайте також» | связанные по тегам/рубрике | 3 карточки; на мобильном первая крупно, остальные строками. |
| «Наступна стаття» | следующая по времени в рубрике | Плашка цвета `--rt` рубрики следующей статьи, заголовок, обложка. |

## Обложки рубрик

- 12 файлов `covers/<slug>.svg`, 1200×675, без текста, без людей, техники, символов сторон и красного креста. Это собственная графика; кредит: «Ілюстрація рубрики «{Рубрика}». Власна графіка редакції.»
- **Когда использовать:** у материала нет `cover` с легальным фото. Fallback — по `rubric.slug`. Не генерировать вместо них псевдо-фото.
- **Кадрирование:** главный мотив — в центральном квадрате, поэтому `object-fit: cover; object-position: center` даёт корректные кадры 16:9, 2:1, 4:3 и 1:1 (см. `mockups/covers-sheet.png`).
- **OG-картинка:** при отсутствии фото можно отдавать обложку рубрики (растр 1200×630 — конвертировать при сборке, например resvg).
- На обложки не накладывать текст и затемнения.
- `alt`: в карточках обложка декоративная (`alt=""`, заголовок рядом); в статье — описание из `<title>` SVG.
- Цвета обложек = `--r-<slug>-cover`; при смене палитры правьте `tokens.css` и `RUBRICS` в `build_covers.py` вместе.

### Кредит фото (когда есть легальное фото)

`<figcaption class="credit">Фото: {автор} / {источник}, ліцензія {лицензия}</figcaption>` — например «Фото: Ім’я Прізвище / Wikimedia Commons, CC BY-SA 4.0». Ссылка на источник и лицензию обязательна. Обрезка или правка чужого фото не дают прав на него.

## Шапка рубрики и тега

- Рубрика: полоса `--rcov` на всю ширину, заголовок 60/36 px белым (контраст ≥ 5.4:1), справа обложка рубрики с маской затухания слева — фон обложки совпадает с полосой. Ниже — чипы популярных тегов рубрики.
- Тег: хлебные крошки, тип страницы «Тег», заголовок, «N матеріалів з {дата}», список с пагинацией; справа «Схожі теги» и «Популярне».

## Поиск и 404

- Поиск: большое поле (фокус — рамка `--ink` + кольцо `--focus`), фильтр рубрики, период чипами (`aria-pressed`), строка «Знайдено N матеріалів за запитом «…»», совпадения выделены `<mark>` (`--mark`). Пустой результат и ошибка поля — в `styleguide.html`.
- 404: код, «Сторінку не знайдено», поиск, чипы рубрик, кнопка «На головну», справа лента. Ответ сервера — 404.

## Тёмная тема

Атрибут `data-theme="dark"` на `<html>`. Чтобы не было мигания, инлайн-скрипт в `<head>` до CSS:

```html
<script>try{var t=localStorage.getItem('theme')||(matchMedia('(prefers-color-scheme: dark)').matches?'dark':'light');if(t==='dark')document.documentElement.dataset.theme='dark'}catch(e){}</script>
```

Кнопка «Тема» в шапке переключает атрибут и пишет `localStorage`. Обложки в тёмной теме не меняются.

## Доступность (AA)

- `python3 design/check_contrast.py`: 112 пар в обеих темах, 0 ошибок (текст ≥ 4.5:1, границы UI и крупный текст ≥ 3:1). Минимум для текста — `--r-groshi` на `--wash`: 4.86:1.
- Видимый фокус `--focus-ring` на всех интерактивных элементах; тап-цели ≥ 44 px.
- `lang="uk"`, иерархия заголовков (одна `h1` на странице; на главной она визуально скрыта), `<time datetime>`, `aria-current="page"` у активной рубрики и страницы пагинации.
- Посещённые ссылки в ленте — `--muted`.
- Анимаций нет; `prefers-reduced-motion` учитывается.
- Добавить skip-link «Перейти до основного вмісту» первым элементом `<body>`.

## Логотип — плейсхолдер

Бренд не выбран. `logo/` — нейтральный временный знак: плитка с полосой заголовка и двумя строками текста, плюс надпись «Новини України» в контурах (Literata Bold). Знак выровнен по сетке 4 px и читается в 16 px. На мобильном в шапке — только `wordtype.svg` (20 px), на desktop — `wordmark-inverse.svg` (36 px). Когда Роман выберет название, знак заменяется целиком; на нём не строить айдентику.

## Чего не делать

- Не использовать цвета, шрифты и элементы чужих медиа; не копировать сетку nv.ua один в один.
- Не выводить «Терміново», «Наживо», «Коротко», «Колонки», пока для них нет данных.
- Не придумывать авторов, экспертов, цитаты и фото людей; демо-тексты из `build.py` не попадают в продакшн.
- Не подключать шрифты из `design/fonts` в приложение — только `next/font`.

## Как пересобрать

```bash
python3 design/covers/build_covers.py      # обложки
python3 design/prototype/build.py          # HTML-прототипы
python3 design/check_contrast.py           # контраст
# логотип (нужны fonttools и uharfbuzz): python3 design/logo/build_logo.py
```

PNG-рендеры сняты Playwright (Chromium) в одноразовом контейнере `mcr.microsoft.com/playwright:v1.56.1-noble`: полная страница, ширина 390 (@2x) и 1440.
